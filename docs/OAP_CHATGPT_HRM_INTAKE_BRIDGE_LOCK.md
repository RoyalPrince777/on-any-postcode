# OAP ChatGPT → HRM Intake Bridge Lock

Status: LOCKED
Owner: Human Authority / Founder
Scope: ChatGPT decisions, OAP approvals, green-light commands, War Room outcomes, GitHub-certified records, SMI/HRM memory intake

## Purpose

This lock defines how decisions made in an external ChatGPT conversation become official OAP memory.

The current ChatGPT conversation is not treated as automatic live HRM memory by itself.

A decision becomes official only when it is captured through a governed path:

1. Founder approval or instruction.
2. Safe summary of the decision.
3. Certified GitHub record or approved HRM intake record.
4. Render deployment when the application must read the change.
5. SMI reads the certified source through canonical/governed memory.
6. HRM/audit records the important action where persistence matters.

## Truth rule

OAP must not claim that every ChatGPT message automatically syncs to live SMI memory unless a real tested bridge exists.

Allowed wording:

- "This chat decision has been committed as a certified record."
- "SMI can read this once the certified source is deployed or ingested."
- "Live SMI chat uses governed memory inside the OAP runtime."
- "ChatGPT-to-HRM automatic sync is BUILDING until the intake route is implemented and tested."

Blocked wording:

- "Everything in this ChatGPT thread is already permanently inside SMI memory."
- "SMI automatically remembers every ChatGPT approval."
- "HRM has live-synced this conversation" without a real receipt.

## Intake states

Every external decision must show one of four states:

- CAPTURED: decision exists in conversation or written note.
- CERTIFIED: decision is committed to GitHub or approved HRM record.
- DEPLOYED: certified source is deployed to live services.
- INGESTED: SMI/HRM has read and recorded it through the governed memory route.

No decision may be called INGESTED without proof.

## Bridge design

The governed bridge must follow this path:

ChatGPT decision / Founder green light
→ Safe decision summary
→ Founder Approval Receipt
→ HRM intake record
→ Canonical memory index
→ SMI governed memory read
→ Audit receipt

## Safety boundaries

The bridge must not ingest private chain-of-thought, hidden reasoning, secrets, passwords, payment details, private keys, or unsafe operational content.

Only safe summaries, decisions, approvals, product locks, architecture rules, governance records, and public/private boundary decisions may be stored.

Founder-only and private Command Center data must remain owner-scoped.

## Required proof before green

The bridge is green only when it has:

1. An intake route or command.
2. Founder approval receipt capture.
3. HRM/audit persistence.
4. Canonical memory index update.
5. SMI read-path confirmation.
6. Tests proving no private chain-of-thought or secrets are stored.
7. A visible receipt showing CAPTURED, CERTIFIED, DEPLOYED, or INGESTED.

Until then, ChatGPT-to-HRM automatic sync remains BUILDING.
