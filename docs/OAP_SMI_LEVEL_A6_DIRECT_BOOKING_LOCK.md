# OAP SMI Level A6 Direct Booking Lock

Status: LOCKED AS FUTURE GOVERNED LEVEL

## Clean naming

- SMI is the intelligence.
- A6 is an operating level, not an agent, product or separate brain.
- Booking is public/action language only when needed.
- OAP Direct is the canonical system name.

## Level meaning

A6 = Governed operational execution.

This is above A5 preparation, but below A7 organism-scale autonomy.

## A6 may do, only after proof and Founder approval

- Execute internal Route Matrix capture.
- Execute Private Guard capture.
- Execute OAP Atlas source-health capture.
- Create Direct request drafts.
- Create supplier readiness checks.
- Create inventory readiness checks.
- Create HRM receipts for approved internal steps.
- Prepare rollback packs.
- Drop back to A5 when evidence is missing.

## A6 may not do

- Self-approve.
- Capture payment.
- Transfer SIKA as money.
- Dispatch people, riders, drivers, vehicles or couriers.
- Confirm a reservation without supplier receipt.
- Claim emergency authority.
- Track hidden location.
- Expose private media.
- Import external marketplace authority.
- Publish public claims without proof.

1. Founder approval.

3. Green Gate pass.

5. Rollback path.
