# Personal SMI Chat Release Checklist

Release is green only when all conditions below are true:

1. The authenticated SMI chat route renders without template errors.
2. Rich answer rendering is client-safe and never injects raw model HTML.
3. Edit, Retry, history search, mobile history drawer and drag/drop attachments render.
4. Render, GitHub and Neon states remain evidence-driven; missing credentials show attention/setup.
5. GitHub mutations remain proposal -> Human Authority decision -> signed receipt -> Living Kernel execution.
6. Response receipts are created only from the actual completed SSE result.
7. Private chain-of-thought is not exposed.
8. Existing Founder-only auth and CSRF boundaries remain unchanged.
9. Repository tests and workflow checks pass.
10. Render deploy finishes successfully before production is called green.
