# OAP Digital Organism — full anatomy autonomy

Canonical flow:

`OAP CORE → NEXUS → Thalamus → SMI Brain → Judgement → Human Authority → Living Kernel → Body Organ → HRM`

## Whole-organism anatomy

- **OAP CORE** — connective context tissue; OAP-owned context enters the organism here.
- **NEXUS** — nervous system; carries signals but does not decide.
- **SMI** — the one and only brain.
- **Living Kernel** — heart; coordinates only approved execution.
- **HRM / JOOG MEMORY** — memory; records context, decisions, outcomes and learning.
- **Human Authority** — sovereign will and final authority.

### SMI biological anatomy

SMI remains organised around real brain anatomy: left/right hemispheres, corpus callosum, frontal/parietal/temporal/occipital lobes, thalamus, hypothalamus, hippocampus, amygdala, cerebellum and brainstem. Synthetic Mind remains an internal SMI organ, never another brain.

### OAP body organs

The Body Systems boundary now explicitly contains OAP-owned organs including Infrastructure, Trust, World/The Spot, Link Up, Tune Core, Commerce Core, SIKA, Post Core, Movement, Media, Youth, Nature and Arena.

OAP Tune Core is the OAP-owned music catalogue/release/rights/royalty workflow. OAP Commerce Core is the OAP-owned storefront/order/payment-intent/fulfilment workflow. OAP Post Core is the OAP-owned Post Office/service/parcel workflow.

## Autonomy law

Every organ may autonomously perform bounded non-consequential work such as observation, self-checking, coherence review, non-consequential retry, drafting, queuing intents and proposing improvements.

No organ may independently approve, self-promote, self-apply improvements, deploy, publish externally, capture payments, transfer money, pay royalties, dispatch drivers, change permissions or roles, migrate production, hand parcels to external carriers, activate physical Post Offices, activate eSIMs, switch carriers or expose precise tracking.

Consequential path remains:

`Intelligence proposes → Guardian protects → Builder creates → Identity validates → Sovereign decides → HRM remembers → Organism grows`

Human Authority remains final.

## Runtime

The existing durable organism worker now carries whole-organism autonomy status and runs the full organism observation/coherence/recovery/growth cycle during its health probe.

The code is deployment-ready for an always-on worker process using:

`python -m mission_control.organism_worker`

Continuous 24/7 execution is only considered live when an always-on compute service is actually running the worker and its database heartbeat is fresh. No web-process daemon thread is used to simulate this state.
