# SMI Interaction Layer — Purple Certification Lane

Status: 🟣 BUILD COMPLETE / LIVE CERTIFICATION REQUIRED

This lane keeps SMI as one intelligence brain. Chat, Voice, Vision, Face Up, Screen Intelligence and Tools are interaction modes over the same governed SMI runtime.

## Canonical surface

- 💬 Chat — primary workspace and default landing state.
- 🎙️ Voice — browser speech capture into the governed chat stream, plus optional spoken reply.
- 👁️ Vision — camera or image capture into the existing governed image-analysis path.
- 📹 Face Up — local camera/mic session with explicit device controls and a bounded frame-to-Vision bridge.
- 🖥️ Screen Intelligence — user-selected screen capture, reduced to one bounded frame, then passed through the governed Vision path.
- 📎 Plus / Tools — files, media, Studio, connected infrastructure and governed actions in one expandable drawer.
- 🧠 Intelligence selector — Auto / Manual / 3 / 7 / 21 / War Room.
- ⏸ Runtime controls — Pause / Resume / Stop remain visible during active work.
- 📚 Continuity — saved conversations, HRM context and receipts remain owned by the existing SMI runtime.

## One-brain routing law

The selector changes review depth, not authority.

- Auto chooses the smallest sufficient bounded depth.
- Manual holds the baseline bounded review until Human Authority selects a deeper mode.
- 3 maps to the existing Instant lane.
- 7 maps to the existing Think lane.
- 21 maps to the existing Deep Dive lane.
- War Room forces the existing bounded War Room advisory review and depth 21. It does not create approval or execution authority.

War Room remains simulation/advisory only. Human Authority remains final.

## Truth boundary

A visible control is not Green Gate evidence.

Every interaction must still prove:

control → UI event → governed backend path → correct result → failure handling → Chronicle/HRM receipt where required → independent verification → Green Gate

Static DOM tests can prove wiring exists. They cannot prove microphone permission, camera permission, screen chooser behaviour, device compatibility, live provider response, production persistence or deployment health.

## Current branch proof claim

This branch may truthfully claim the interaction layer is **implemented for certification**. It may not claim the whole interaction layer is production-green until live evidence is captured.

Face Up is deliberately bounded in this branch: camera/mic preview and explicit frame capture are implemented, but continuous live SMI participation, multi-view and spatial capabilities remain future certification work. The UI states that limitation directly.

No interaction mode grants automatic approval, automatic deployment, payment, dispatch or other consequential execution.
