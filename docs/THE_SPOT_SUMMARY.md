# The Spot summary

This branch keeps The Spot simple while making its promises more precise.

The public front door is postcode-first, browse-first, and free to browse. Priority cards use visitor-readable state labels instead of implying every downstream transaction is live. All canonical Spot capabilities remain discoverable, while My World and other protected actions retain their existing authentication boundaries.

The change does not create a second location engine, movement stack, market core, identity system, messaging system, memory, security layer, or intelligence brain. It composes the existing OAP organs.

Runtime proof is still required before merge/deploy status can be called green.
