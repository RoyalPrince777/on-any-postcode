# OAP Spatial Presence v1

## Identity

- System: **OAP Spatial Presence**
- User experience: **Face Up Spatial**
- Parent specialist capability: Technology Intelligence
- SMI remains one brain; this does not add an Intelligence World.

## Pipeline

1. Authorised Spatial Capture — multi-view RGB-D, LiDAR/depth, monocular fallback, optional privacy-reduced ISAC context.
2. Matrix Spatial Reconstruction — session-scoped geometry/world context.
3. OAP Edge Semantic Compression — interaction-critical detail first; static/background context cached or represented semantically.
4. Guardian Presence — consent, minimisation, no persistent biometric clone, no covert tracking.
5. Nexus Spatial Transport — local-first/current-network transport with adaptive QoS.
6. Face Up Spatial Render — XR headset/smart glasses, light-field, volumetric or 2D fallback.
7. Oasis Presentation — human-safe presentation layer.

## Network strategy

Current operational fallbacks are preferred before future-radio research paths:

- local LAN / Wi-Fi
- fibre + OAP Edge
- 5G / 5G-Advanced
- mesh / device-to-device
- NTN / satellite fallback

Research paths:

- **OAP 7–21 GHz experimental cmWave envelope** — an internal research target, not a claim about the final standardized 6G band.
- D-band 110–170 GHz research.
- sub-THz 90–300 GHz research.
- photonic-wireless research hooks.

## Adaptive spatial QoS

The software does not require every raw point to cross the network. It prioritises face/hands and interaction-critical geometry, uses medium body detail, and caches or semantically represents static background/world context. Weak links fall back to ordinary Face Up 2D rather than failing the session.

## Evidence gates

Software readiness is separate from physical proof. The following remain false unless signed/configured evidence exists:

- volumetric capture hardware proven
- spatial display hardware proven
- OAP 7–21 GHz radio hardware proven
- D-band/sub-THz hardware deployed
- live 6G network proven
- terabit session throughput
- sub-millisecond end-to-end latency

## Privacy and authority

- explicit capture consent required
- raw media and raw point clouds are not exported by default
- no persistent biometric clone
- no hidden-person or through-wall person tracking
- Matrix receives privacy-reduced session state
- no autonomous radio control
- external providers have no OAP authority
- Human Authority remains final
