# The Spot — Next Proof Gates

This branch improves the public front door only. It does not promote gated transactions to live.

Next gates, in order:

1. Prove postcode/location resolution on the deployed runtime without treating query text as verified location.
2. Keep Pulse and Signal public surfaces bounded and separate from private LinkUp messages.
3. Prove Events discovery data before enabling booking persistence.
4. Prove Market merchant verification before checkout or regulated payment activation.
5. Prove Movement routing/runtime gates before dispatch, payment, carrier activation, or live tracking.
6. Connect authenticated Safety reporting with safeguarding and escalation boundaries.
7. Keep My World Founder-only under the current private-dashboard access law.
8. Replace external bootstrap location/weather dependencies only when OAP-owned Earth/Weather observation has real runtime proof.

No gate is green merely because a card or route renders.
