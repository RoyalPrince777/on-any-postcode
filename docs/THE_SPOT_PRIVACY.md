# The Spot location privacy boundary

The public Spot does not require device location.

A visitor may supply a postcode deliberately. That value is treated as request context, not as verified residence, identity, GPS position, or proof of presence.

The front door must not silently collect precise device coordinates. Private identity/location records remain inside their existing protected ownership boundary.

Location/weather lookup may resolve visitor-supplied place text through the existing bounded location service. This does not authorize tracking, dispatch, navigation, or persistent location history.

Any future precise-location feature requires an explicit user action, a clear purpose, minimal collection, appropriate retention rules, and the existing OAP safety/governance gates.
