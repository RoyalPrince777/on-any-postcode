## v0 install proof

The public web origin exposes:

- a standards-based web app manifest;
- 192px and 512px maskable install icons;
- a root-scoped service worker;
- a browser install controller;
- a static public offline-safe page; and
- shortcuts for The Spot, The Link, Link Up and Movement.

The service worker deliberately does not cache dynamic page responses. It
pre-caches only the reviewed public shell resources.

## Protected data law

The following routes and data classes are network-only and outside every OAP OS
offline cache:

- Auth and Founder enrollment;
- My World and owner-scoped profiles;
- Mission Control and War Room;
- Infrastructure and operational evidence;
- private messages and conversations;
- HRM memory and audit records;
- approval receipts and Human Authority decisions; and
- every non-GET request.

An offline public shell must never be interpreted as offline authority,
identity, messaging, approval or execution.

## Upgrade path

1. Deploy and verify manifest, service-worker scope and install prompt.
2. Install on a real Android device and test update/recovery behavior.
3. Certify that private responses and user data never enter browser caches.
4. Produce a separately reviewed signed Android package.
5. Add the governed OAP App Store catalogue, package signatures and updater.

Each later stage is additive. It must not remove approved OAP structures or
weaken the public/private boundary.
