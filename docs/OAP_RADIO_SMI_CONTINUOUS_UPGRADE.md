# OAP Radio — SMI Continuous Upgrade Contract

Scope: independent first-party OAP Radio, online-first and lawful FM licensing. This is a review protocol, not a deployed autonomous agent, model upgrade, live stream or regulatory authority.

## Command and accountability
Founder Final → SMI (advisory coordination) → Captain ALL IN (work sequencing) → existing specialists → verification. Guardian enforces safety and fail-closed boundaries; HRM retains governed evidence. No role may override Founder authority or UK regulatory requirements.

## Upgrade during the work
For each meaningful radio code change, SMI review must:
1. Inspect exact revision and changed radio files, existing interfaces and tests before proposing additions.
2. Reuse canonical radio_core, OAP Music, rights adapters, Universal Player and existing owner-scoped routes; avoid duplicate registries and players.
3. Identify the smallest verifiable improvement, add a focused regression and run it where execution is available.
4. Classify results as committed, test-passed, merged, deployed, observed-live, or externally licensed; never collapse stages.
5. Keep STOP fail-closed on unknown/malformed values. Do not trust caller-provided LIVE flags or stream URLs.
6. Require independently observed transport health, Founder approval, content rights and safeguarding before any public LIVE indicator or stream release.
7. Record exact evidence, blockers and recovery, then continue bounded authorised work without repeated approval ceremonies.

## FM and deadline truth
The proposed 26 October 2026 Ofcom deadline is UNVERIFIED until matched to an official current notice, eligible service category and application window. Do not file, transmit, purchase spectrum or claim an FM licence automatically. OAP Radio Authority is an internal governance function, not a substitute for Ofcom.

## Reporting
Only report progress percentages when a defined evidence denominator exists. Purple = work/review; Green = proven specific gate; Red = proven blocker; Unknown = unverified. No autonomous model retraining, security bypass, rights grants, publishing or external submissions.
