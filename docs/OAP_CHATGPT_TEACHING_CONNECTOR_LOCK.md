# OAP ChatGPT Teaching Connector Lock

Status: LOCKED
Owner: Human Authority / Founder
Scope: Command Center, Connected Systems, SMI, HRM, Guardian, ChatGPT, certified OAP records

## Placement

ChatGPT is registered as a controlled teaching and architecture-support connector under:

Command Center -> Connected Systems -> Intelligence Providers -> ChatGPT

ChatGPT is not a public OAP product, not a hidden controller, not a replacement for SMI, and not a replacement for Human Authority.

## Purpose

ChatGPT may help the Founder:

- explain OAP architecture
- draft safe system laws
- prepare implementation plans
- review risks
- write certified docs
- inspect code through approved connectors
- propose upgrades
- summarize decisions
- create HRM intake records for approval

## Teaching rule

SMI may learn from ChatGPT only through certified records.

Loose chat messages are not automatically permanent OAP memory. A ChatGPT idea becomes teachable to SMI only when it is:

1. approved by Human Authority,
2. written into an OAP document, code file, issue, pull request, migration, or HRM intake record,
3. checked for public/private boundary,
4. checked by Guardian rules,
5. committed or stored in an approved record system,
6. deployed or ingested through a governed route when runtime memory is required,
7. marked with a truthful state: CAPTURED, CERTIFIED, DEPLOYED, INGESTED, BUILDING, LOCKED, or NEEDS APPROVAL.

## Memory state language

CAPTURED means written down in chat or a draft.

CERTIFIED means approved and committed/stored as an official OAP record.

DEPLOYED means the certified record is live in the app/repo runtime package.

INGESTED means SMI/HRM has actually read and recorded the item through a real memory-ingest path.

No item may be called INGESTED only because it appeared in ChatGPT.

## Authority boundary

ChatGPT can propose, draft, review, explain, and help execute connector actions when the Founder instructs it and the connected tool allows it.

ChatGPT cannot independently approve itself, expand OAP permissions, bypass Guardian, change auth/security, migrate production databases, spend money, transfer value, publish public claims, or act as Human Authority.

## Privacy and secrets

ChatGPT-connected records must never expose secrets, API keys, private tokens, production credentials, private Founder images, private HRM records, or protected member information in public files.

Public summaries must be safe. Private operational records stay inside Command Center, HRM, protected docs, or approved private storage.

## Provider distinction

ChatGPT is an external intelligence provider connector.

SMI is the OAP sovereign intelligence layer.

HRM is the official memory and record layer.

Guardian is the safety and boundary layer.

Human Authority is final.

## Correct operating phrase

ChatGPT helps teach SMI through certified records. SMI does not blindly absorb chat. HRM remembers only what has been approved, recorded, and ingested through a governed path.

## Green condition

This connector is green only for documentation, architecture support, and certified record creation.

Automatic live memory ingestion remains BUILDING until a real endpoint, database table, audit receipt, and SMI readback test exist.
