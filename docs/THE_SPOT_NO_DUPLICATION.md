# The Spot no-duplication rule

The Spot is a composition layer.

It must link to and present canonical OAP capabilities rather than create parallel versions of:

- LinkUp messaging;
- My World identity;
- SIKA ledger;
- Market commerce core;
- Movement Intelligence;
- Earth/Weather Intelligence;
- Aegis safety/security;
- HRM memory/audit;
- Kernel authorization;
- SMI reasoning.

A new Spot feature should first identify its canonical owning organ. If an owner already exists, The Spot integrates that owner rather than implementing a competing store, brain, ledger, permission system, or execution path.
