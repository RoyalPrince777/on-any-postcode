# OAP Earth Intelligence v0

OAP Earth Intelligence is the planet-context layer for OAP World and The Spot.

Current live composition:

- Spatial context: Postcode → Borough → County / Region → Country → Continent → Global → Universe.
- Weather Intelligence: current observation, forecast interpretation and local advisory signals.
- The Spot connection: local Earth context is returned with the existing location + weather lookup.

Gated until verified OAP-controlled data paths exist:

- Environment observations.
- Terrain intelligence.
- Hazard intelligence.
- Nature / wildlife observations.
- Earth memory and learned environmental history.

Earth Intelligence must not fabricate readings, hazards or environmental conditions. A missing verified source remains unavailable/fail-closed.
