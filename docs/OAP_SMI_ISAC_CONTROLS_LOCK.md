## War Room controls

War Room is the decision-review layer.

It checks:

1. What is being changed.
2. Which OAP organ owns it.
3. Whether it duplicates an existing organ.
4. Whether it affects public/private boundaries.
5. Whether it changes money, identity, safety, deployment, data, radio, routing, or publishing.
6. Whether Guardian must block or reduce scope.
7. Whether Human Authority approval is required.
8. Whether tests/live checks prove green.

War Room can recommend. War Room cannot self-approve consequential action.
