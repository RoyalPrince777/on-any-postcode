# SMI exact-pixel layer lineage evidence v0.1

The approved flattened `3325.png` remains the only source of visual identity.
This gate accepts a private seven-layer bundle only when every layer is a
same-size RGBA PNG, every visible RGB pixel exactly matches the pixel at the
same coordinate in the approved SHA-256 source, and alpha is binary. Empty
masks and seven full-frame copies are rejected.

This proves only pixel ancestry. It does not prove that a mask represents the
named anatomy, that overlaps and occlusion are correct, that movement is
natural, that speech matches played audio, or that Human Authority approved
the result. The runtime remains inactive and emits no frames.

## Still required

1. Private human-reviewed masks for eyes, head, breathing torso, mouth, face,
   hands, and upper body.
2. Visual registration and occlusion proof against the unchanged artwork.
3. Real motion, played-audio viseme, STOP, reduced-motion and Android evidence.
4. Human Authority final approval.

No layer path or bytes are exposed through the public SMI route, no telemetry
is added, and no visible Live Status panel is introduced.
