# The Spot green gates

A green Spot requires separate evidence for separate layers.

## Front door
- route responds successfully;
- all canonical capabilities remain discoverable;
- no signup wall for browsing;
- no form on the main front door;
- mobile layout verified.

## Location
- visitor-supplied postcode is treated as unverified context;
- real lookup resolves safely;
- hierarchy/weather claims come from the location capability, not raw query text.

## Private boundary
- anonymous access cannot enter My World, LinkUp private messaging, Mission Control, or Founder dashboards.

## Transactions
Market checkout, bookings, movement dispatch, payments, tracking, verification, and protected reporting each require their own runtime proof. Their card existing in The Spot is not evidence of operational readiness.
