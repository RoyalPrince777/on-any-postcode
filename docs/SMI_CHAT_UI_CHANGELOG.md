# Personal SMI Chat UI finalisation

Branch: `smi-tools-green-gate`

This branch upgrades only the Personal SMI chat experience and leaves the public OAP surface unchanged. It adds rich safe rendering, message edit/retry controls, conversation search, compact mobile navigation, evidence-backed tool inspection, governed GitHub action cards, completed-response JOOG/HRM receipt cards, drag/drop attachment forwarding and truth-state signalling. No connector receives a cosmetic green state and no consequential action bypasses Human Authority, signed receipts or the Living Kernel.
