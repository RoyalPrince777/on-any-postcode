# OAP Founder Signal Noise Filter Lock

Status: LOCKED
Authority: Human Authority / Founder
Scope: All future OAP app copy, dashboard labels, runtime routes, docs, specs, commits and checkpoint wording.

## Master rule

Founder chat is instruction input, not app copy.

The system must extract only the clean operational requirement and discard conversational noise, repeated approvals, shorthand, emotional phrasing, typos, rough wording and temporary working language.

## What may enter the app

Only system-needed material may be written into code, dashboards, API responses or docs:

- stable route names
- canonical product names
- locked vocabulary
- safety boundaries
- public/private placement
- proof requirements
- state labels
- checkpoint IDs
- Green Gate rules
- Guardian/Aegis blocks
- HRM receipt requirements
- Human Authority approval rules
- short user-facing copy that is intentionally product copy

## What must not enter the app

Do not copy raw chat wording into the product unless the Founder explicitly marks it as public copy, brand copy or locked vocabulary.

Do not include:

- casual chat phrasing
- repeated green-light messages
- filler words
- private working comments
- temporary names that were not locked
- speculative wording
- over-explained internal notes
- anything that exposes private Command Center operations publicly
- anything that turns an unproven feature green

## Strip process

Before writing to the repository, every Founder instruction must pass this filter:

1. Extract intent.
2. Keep only the system requirement.
3. Map it to the right organ, route, checkpoint or safety gate.
4. Use canonical OAP vocabulary.
5. Remove noise.
6. Keep public copy clean and short.
7. Keep private dashboard text functional.
8. Mark unproven work Building or Locked.
9. Never fake green.
10. Preserve Human Authority final approval.

## Examples

Raw Founder signal:

> also all movement intelligence booking finish all missing gaps

Clean system requirement:

> Add Movement and Booking checkpoint coverage for proof gaps, Green Gate state, Guardian boundary, HRM receipt requirement, and locked real-world claims.

Raw Founder signal:

> Don't write anything in the app that am saying strip of the noise only keep what the system needs lock in

Clean system requirement:

> Add a Founder Signal Noise Filter rule: conversational input must be transformed into clean system requirements before entering code, docs, dashboards or public copy.

## Product copy rule

Public OAP World copy should sound human, clear and simple.
Private Command Center copy should be precise, short and operational.
Docs should record the rule, not the whole conversation.

## Locked line

Founder speaks in signals. OAP stores clean requirements.
