# OAP Founder Signal Noise Filter Lock

Status: LOCKED
Authority: Human Authority / Founder
Scope: All future OAP app copy, dashboard labels, runtime routes, docs, specs, commits and checkpoint wording.

## Master rule

Founder chat is instruction input, not app copy.

The system must extract only the clean operational requirement and discard conversational noise, repeated approvals, shorthand, emotional phrasing, typos, rough wording and temporary working language.

## What may enter the app

Only system-needed material may be written into code, dashboards, API responses or docs:

- stable route names
- canonical product names
- locked vocabulary
- safety boundaries
- public/private placement
- proof requirements
- state labels
- checkpoint IDs
- Green Gate rules
- Guardian/Aegis blocks
- HRM receipt requirements
- Human Authority approval rules
- short user-facing copy that is intentionally product copy

## What must not enter the app

Do not copy raw chat wording into the product unless the Founder explicitly marks it as public copy, brand copy or locked vocabulary.

Do not include:

- casual chat phrasing
- repeated green-light messages
- filler words
- private working comments
- temporary names that were not locked
- speculative wording
- over-explained internal notes
- anything that exposes private Command Center operations publicly
- anything that turns an unproven feature green

## Strip process

Before writing to the repository, every Founder instruction must pass this filter:

1. Extract intent.
2. Keep only the system requirement.
3. Map it to the right organ, route, checkpoint or safety gate.
4. Use canonical OAP vocabulary.
5. Remove noise.
6. Keep public copy clean and short.
7. Keep private dashboard text functional.
8. Mark unproven work Building or Locked.
9. Never fake green.
10. Preserve Human Authority final approval.

## Examples

Raw Founder signal:

> also all movement intelligence booking finish all missing gaps

Clean system requirement:

> Add Movement and Booking checkpoint coverage for proof gaps, Green Gate state, Guardian boundary, HRM receipt requirement, and locked real-world claims.

Raw Founder signal:

> Don't write anything in the app that am saying strip of the noise only keep what the system needs lock in

Clean system requirement:

> Add a Founder Signal Noise Filter rule: conversational input must be transformed into clean system requirements before entering code, docs, dashboards or public copy.

## Product copy rule

Public OAP World copy should sound human, clear and simple.
Private Command Center copy should be precise, short and operational.
Docs should record the rule, not the whole conversation.

## Locked line

Founder speaks in signals. OAP stores clean requirements.


## OAP World / SMI agent no-echo interface protocol

Applies to OAP World and every first-party surface, including The Spot, The Link, Mail, Arena, Market, OAP TV, My World and the private SMI Command Center. This is a cross-surface product rule, not evidence of deployed runtime enforcement.

- Founder speech, chat prompts, internal agent plans and approval signals are **private control inputs**, not headings, hero slogans, notifications, fake chat transcripts, page copy or bot dialogue.
- Never spawn visible bots, avatars, agent cards or assistant chatter solely to restate what the Founder said. One canonical SMI intelligence; specialist agents work as governed advisory roles, not duplicated minds.
- Agent names may appear as concise functional labels for actual controls, responsible advisory roles, or explicit navigation help. Agents may respond when directly invoked or when a real task needs explanation, with the minimum useful evidence and next action.
- Do not present speculative agent activity, automatic fixes, delivery, permissions, CI, deployment or production readiness as accomplished. Unknown remains Unknown.
- Preserve existing features, routes, labels and intentional user-generated content. Do not delete legitimate messages, user-authored posts, accessibility labels, agent configuration, audit receipts or security alerts under the guise of noise reduction.
- Keep private SMI/Founder controls out of public pages. Respect canonical My Card identity, authorisation, Guardian/HRM boundaries and Founder Final.
- Prefer a plain functional UI: navigation label, real state, short error, necessary action. No duplicated dashboards or extra status prose.

### Acceptance checks required before release

1. Audit rendered copy and agent entry points in each OAP World surface; explicitly distinguish user-authored content from injected Founder-command echoes.
2. Add regression tests for no command-to-copy reflection, no unsolicited fake agents, and preserved working navigation/accessibility/user content.
3. Verify anonymous/member/Founder visibility boundaries and existing security gates.
4. Test mobile and browser views at the exact release commit. A policy document or passing unit test alone is not a site-wide implementation proof.
5. Keep merge, deployment and customer exposure blocked until governed evidence and Founder Final authorisation.
