# SMI Chat UI 100% Truth Gate

This release closes the remaining Personal SMI chat UX gap without weakening the existing governance boundary.

Implemented surfaces:
- rich safe answer rendering for headings, lists, quotes, links, inline code and fenced code;
- Edit and Retry message actions;
- searchable conversation history and mobile history drawer;
- compact live truth-state indicator sourced from the authenticated SMI health route;
- connected Render, GitHub and Neon inspection from the composer;
- governed GitHub mutation flow from chat: exact proposal, Human Authority decision, signed receipt, Living Kernel execution;
- real response receipt cards derived from the completed SSE result rather than cosmetic status;
- drag-and-drop forwarding into the existing governed attachment inputs;
- compact responsive 2027-style layout.

Truth boundary: a connector or action is never labelled successful from UI state alone. Consequential GitHub actions remain receipt-bound, replay-protected and fail closed through the existing Founder tool backend. Private chain-of-thought remains private; only safe operational stages are displayed.
