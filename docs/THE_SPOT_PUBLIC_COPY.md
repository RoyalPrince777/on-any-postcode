# The Spot public copy principles

Public copy should answer three questions quickly:

1. Where am I? — The Spot is the postcode-first local front door.
2. What can I open? — The priority capabilities and full directory remain visible.
3. What needs protection? — Protected or gated actions say so without exposing internal architecture.

Avoid provider names, deployment language, internal blockers, infrastructure details, and generic claims that everything is live.
