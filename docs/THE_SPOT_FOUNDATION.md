# The Spot foundation

**Brand:** ON ANY POSTCODE

**Front-door law:** One World → One Front Door → Many Systems Inside.

**Local product law:** The Spot starts at the postcode and connects outward without replacing the systems it presents.

**Access law:** Public browsing is open. Authentication appears only when a protected action requires it.

**Truth law:** Surface availability and transactional readiness are different claims and must remain visibly separate.

**Authority law:** A public interface never bypasses Identity, Aegis, Registry, Kernel authorization, Human Authority, HRM audit, or the owning organ's runtime gates.
