# OAP Connected Systems Expansion and SMI Teaching Lock

Status: LOCKED
Owner: Human Authority / Founder
Scope: Command Center, Connected Systems, HRM Memory Intake, SMI governed memory, OAP Image Vault, plugin/connectors.

## Purpose

This lock keeps OAP open for future approved connectors while preventing unsafe plugin sprawl, secret leakage, fake integration claims, or uncontrolled memory ingestion.

OAP may connect to more tools over time, like the Founder uses connected tools in ChatGPT, but every connector must stay under Command Center governance.

## Placement

Connected tools are private infrastructure organs. They are not public OAP products.

Correct location:

OAP World -> Command Center -> Connected Systems

Current connector families:

- Code and build: GitHub.
- Live deployment: Render.
- Production data: Neon.
- File and image vault: Google Drive, conversation file library, OAP Image Vault, OAP Media Vault later.
- Communication and operations: Gmail, Calendar, Contacts where approved.
- Design and creative tools: Canva, Figma, image tools where approved.
- Music handoff tools: Spotify, Apple Music, TikTok, SoundOn, distributors and aggregators only when legal/API/partner routes are real and approved.

## Founder-open connector rule

The Founder may install or approve more connectors later.

A connector becomes OAP-ready only after it has:

1. A named owner system inside Command Center.
2. A declared purpose.
3. A public/private boundary.
4. Allowed actions.
5. Blocked actions.
6. Secret-handling rules.
7. HRM audit record requirement.
8. Guardian fail-closed behaviour.
9. Human Authority approval for write, deploy, spend, publish, delete, migrate, or permission-changing actions.

Until these exist, the connector is DISCOVERY or BUILDING, not LIVE.

## Plugin safety law

Plugins and external tools may assist OAP, but they do not control OAP.

GitHub records code and certified docs.
Render runs approved deployments.
Neon stores approved production data.
Drive/File Library stores files and images.
Design/music/content tools support creation and handoff.

No connector may:

- Self-install without Founder approval.
- Read private data without a task reason.
- Write, delete, deploy, migrate, spend, publish, or change permissions without approval.
- Store secrets in public files or logs.
- Claim a partnership, official integration, payment route, distribution route, or live capability without proof.
- Replace HRM, Guardian, Living Kernel, Command Center, or Human Authority.

## Image movement law

Images move into the correct vault, not randomly into public code.

Approved image destinations:

- Public website assets: small public logos, icons, safe brand images.
- OAP Image Vault: private originals, Founder images, brand source files, AI-generated source images.
- OAP Media Vault later: creator covers, radio artwork, TV thumbnails, campaign assets.
- OAP Market: product images after product record exists.
- OAP Music / Media: release covers only with rights proof.

Private Founder images remain private unless explicitly approved for public use.

## Connector status labels

- CONNECTED: tool is available to the Founder.
- REGISTERED: tool has a Command Center owner and purpose.
- GUARDED: tool has public/private and permission rules.
- AUDITED: important actions create HRM/audit records.
- CERTIFIED: tested and approved.
- LOCKED: intentionally unavailable until proof/compliance/approval exists.
