# SMI Chat A7 Controls

SMI Chat is the Founder intelligence workspace and interaction surface. It does not duplicate specialist OAP systems.

## Canonical routing

- SMI Chat owns conversation interaction, send/stop, visible safe work state, and capture entry points.
- SMI AUTO selects the relevant existing intelligence and tools.
- OAP Studio Intelligence remains the canonical media intelligence engine.
- The Link remains the canonical human communication system.
- HRM/JOOG remains the continuity and governed learning layer.
- Guardian and Human Authority remain the consequential-action boundary.

## Capture controls

- Voice input uses the canonical SMI voice controller.
- Camera requests native device permission, captures one bounded still frame, stops the camera track, and reuses the existing image/media route.
- Share Screen requests native display permission, captures one bounded still frame, immediately stops sharing, and reuses the existing image/media route.
- Unsupported or denied capabilities are truth-labelled and never shown as successful.
- Raw camera/screen streams are not persisted by this controller.

## No duplication law

Before creating a capability, check whether OAP already owns it. If it exists, connect it. If incomplete, finish it. Create a new engine only when the capability is genuinely absent.

This change does not alter Founder authentication, passwords, permissions, production deployment, or A7 execution authority.
