# The Spot architecture

The Spot is a public product surface inside OAP World, not a second operating system or intelligence core.

Canonical product path:

`OAP World → The Spot → The Link → LinkUp`

The Spot composes existing product capabilities. It does not duplicate their stores, intelligence, governance, security, routing, commerce, or messaging engines.

Public browsing stays separate from protected actions. My World and LinkUp retain their existing authentication boundaries. Transactional capabilities retain their own readiness gates.

Location context follows the OAP spatial hierarchy:

`Postcode → Borough / District → County / Region → Country → Continent → Global → Universe`

A postcode in the Spot URL is visitor-supplied context only. Resolved location/weather data remains the responsibility of the existing location experience, and production movement remains the responsibility of OAP Movement Intelligence.
