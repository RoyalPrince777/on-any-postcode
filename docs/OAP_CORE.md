# OAP CORE

OAP CORE is the canonical OAP-owned contextual intelligence layer used by the SMI signal path.

## Canonical language

- System name: **OAP CORE**
- Code field: `oapcore`
- Flow: `OAP CORE -> NEXUS -> Thalamus -> SMI Brain -> Judgement -> Human Authority`

## Boundaries

OAP CORE is not a generic secret store and does not grant execution authority. Private values are filtered by the Thalamus before biological-brain analysis. Human Authority remains final for consequential action.

The older `oapdata` and `metadata` names exist only as compatibility aliases at the request contract boundary and must not be used by new OAP code.
