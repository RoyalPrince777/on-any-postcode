# OAP Library — Mind / Body / Soul release evidence

Status: evidence checklist, **not** a certificate of copyright or book completion.
PR #518 is an isolated policy/rotation candidate. Never advertise a publishing
licence, completed manuscript, paid entitlement, or protected reader from a
passing unit test alone.

## MIND — title and rights truth
For EACH actual book and EACH edition, collect:
- Immutable book and edition IDs, complete approved manuscript/file hash and revision.
- Named human creator(s), contributor agreements and proof of publisher authority.
- Separate rights evidence for artwork, quotes, photography, sources, recipes,
  voice performances, translations and adaptations as applicable.
- Territory, language, formats, time window, revocation/expiry, paid sales,
  previews and an **explicit seven-day free-rotation grant**.
- Public-domain/open-licence attribution and compatibility where applicable.
- Written Founder approval; missing or ambiguous evidence means NOT PUBLISHABLE.

Do not substitute an ISBN, GitHub commit or a citation for rights ownership.
Food Book Core remains free independently of rotating premium editions.
A private or Founder-owned item never becomes a public candidate.

## BODY — actual first-party reader and entitlement
Before exposing paid content: implement durable authenticated owner-scoped
purchase entitlements derived only from independently verified payment records
(no request-supplied purchased IDs); verified creator licence records; audited
publish/unpublish and rotation schedules; clock/expiry and withdrawal handling;
no cached paid-content leak after expiry; renewal-safe original purchases.
Preview must not expose the complete book. Protected streaming, token expiry,
watermarking and read authorization must occur on the server.

The current rotation module is a deterministic plan, **not** a scheduler.
The current access module is a policy, **not** a payment system or reader.

## SOUL — youth, safety, privacy and release
Youth release requires safeguarding and actual age eligibility; no private
catalogue projection. Protect personal library data from other members,
search indexing and content caches. Capture deterrence is platform-specific:
Android FLAG_SECURE for supported protected app windows; iOS capture state
cover/pause; web watermark and policy for initiating display capture, but never
claim screenshot-proof or camera-proof protection.

Release gate: exact branch/head and CI, tests of real authenticated routes
against rights/entitlement persistence, rollback proof, signed source and
licence records, independent security/accessibility review and Founder Final.
No merge, migration, payment execution or deployment under this isolated PR.
