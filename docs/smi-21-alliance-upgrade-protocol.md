## Execution protocol — upgrade only

1. **Discover:** Inspect main branch, existing agents, routes, tests, workflows, and evidence before adding functionality.
2. **Deduplicate:** Roles are responsibility labels on existing SMI work, not independent services unless deployment is explicitly built and verified. Shere Khan challenges evidence; Agent Smith designs adversarial cases; Twins own breakpoint and recovery, avoiding overlap with Fox/Trinity.
3. **Execute:** Implement bounded, approved changes without repetitive approval prompts or stopping after each small fix. No unnecessary stages, duplicate reports, demos as completion, cosmetic percentages, or avoidable simulations.
4. **Challenge:** Run relevant real tests, security checks, regression checks, and negative cases. Agent Smith operates only against authorized test surfaces.
5. **Verify:** Record commit SHA, workflow result, runtime/environment, failed cases, and unresolved gates. CI passing does not imply installed-device or production readiness.
6. **Recover:** If any required gate fails, keep merge locked, identify the precise failure, repair it, and rerun relevant checks. Never declare false Green or bypass security.
7. **Report:** Compact **Done / Next / Recovery** with explicit proven/unproven boundaries and Founder Final for new irreversible decisions.
