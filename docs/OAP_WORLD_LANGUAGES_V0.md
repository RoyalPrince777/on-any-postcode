# OAP World Languages v0

## Scoped first phase

OAP World Languages is a public, local-first learning surface inside OAP World.
Its first release provides:

- a selector covering Africa, Asia, Europe, North America, South America,
  Oceania and Antarctica;
- one bounded starter lesson for every continent context;
- a wider, clearly labelled language catalogue for each continent;
- bounded present-tense conjugation tables for English, Spanish, French and
  Portuguese; and
- official South London learning links for Lewisham, Lambeth, Southwark and
  Croydon.

Antarctica is handled truthfully: it has no permanent resident language
community. Its starter path is international field communication and is not
presented as a native Antarctic language.

## Privacy and truth boundary

The v0 surface is server-rendered and read-only. It does not:

- create learner accounts or store progress;
- record audio, video or precise location;
- use advertising or tracking scripts;
- call a translation, conjugation or generative language provider;
- claim fluency, certification or native-speaker validation; or
- read or translate private Link Up conversations.

Starter content must receive community and native-speaker review before it can
become Certified. Official local-resource links carry a review date because
course availability can change.

## Phase two lock

Phase two may add user-chosen language practice and translation tools to Link
Up. That work is not active. It requires separate privacy, youth-safety,
safeguarding, accuracy, consent and provider review. Link Up message ownership,
encryption boundaries and the existing language law remain unchanged.
